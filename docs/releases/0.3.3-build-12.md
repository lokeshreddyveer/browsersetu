# Browser Setu 0.3.3 (build 12)

Mac: notarized DMG. iPhone/iPad: TestFlight build 12. Same version, higher build number.

## Added since build 11
- Downloads: speed and time left, SHA-256 copy and verify, low-disk warning, finish notifications, diagnostics, folders by site or profile.
- Security: redirect-chain alerts, a security events list, Relaunch Without Extensions, extension permission warnings.
- Tabs: mute and audio badge, sort, snooze and schedule, nested groups, group search, pinned-tab close prompt, idle-group sleep, cross-window tab search.
- Resource governor: Battery Saver and Custom profiles, battery/heat awareness, CPU and energy estimate, startup timing.
- Privacy: referrer control, custom list import, a per-page report in the shield's "This site" panel.
- Profiles: icons and colours, open in profile, sites assigned to a profile, temporary profile, downloads per profile.
- Media: per-player details, subtitles, AirPlay picker, other-tab controls, sleep timer, recently played.
- Reading: reader style (font, size, spacing, width, background), progress, saved-article search, citations.
- New tab page: Google as default search, new-tab modes, colour/blend/photo backgrounds, voice search (on device), a redesigned Customize panel.
- Search and knowledge: Search Everything covers reading list, closed tabs and sessions; Bookmark Tools; history retention.
- Split view (Mac): linked scrolling, compare, link to the other panel, reopen last split.
- Developer tools and utilities, Network tab, saved pages, password strength, saved addresses.
- Reliability: Session Time Machine, measured Health values, diagnostic log and report, unresponsive-page check.
- Automation: open several links, clipboard tools, batch bookmark actions, workflow history and sharing. Mac Dock menu and Services.

## Fixed
- Split panels no longer swap places when clicked; chat pages keep their scroll position when switching tabs; tab hover shows one thing, not two.
- Address bar folding is smoother; iPhone landscape uses one slim bar; "Now using Wi-Fi" no longer repeats; video is no longer paused again after you press play in the full-screen player.
- iPhone and iPad: tab swipe-to-close and taps freed from drag handlers (drag-reorder and link-drop are Mac-only for now).

## Checked
- New unit tests (about 90 across 17 suites) compiled and ran on the Mac; two expectation mistakes were fixed.
- Mac and iOS builds compile and install.

## Not checked
- Most new screens were not exercised by hand; iPhone landscape, tap behaviour, voice search and saved web archives are untested on devices.
- Full test suite not re-run; iPhone/iPad tests not run.
