# Browser Setu 0.3.1 (build 5)

Mac: notarized and stapled DMG (SHA-256 c31548889144982957efcdfc53c112cdc9bdb1ddcf3c12dc43b390a5b3700c38). iPhone/iPad: TestFlight build 5, and installed on the author's iPhone. Built 17 October 2026.

## Fixed
- **Themes now reach the whole window.** The strip above the toolbar showed the system's grey because the theme background stopped short of the title bar.
- **The toolbar takes the page's colour.** It used to need a page that named a theme colour, which most do not; it now reads the page's own background. Under a theme the page adds a lighter touch, and a colour that would clash with the window only adds a faint wash.
- **Dragging a tab to another window** works from tab bars and sidebar lists, and the moved page no longer goes blank (the window it left was taking its page back as it closed).
- **One Row** has the bookmark, downloads and More menu the other layouts have.

## New
- Toolbar buttons for **workspaces, profile, split view**, history, bookmarks, find and the command palette in Classic, Minimal and One Row (workspaces and split view are on by default; the rest are in Settings › Appearance › Toolbar). The More menu has workspace and split-view entries.
- Split view and several windows are explained in Settings › Tabs; workspaces are tidy rows with colour swatches.
- A style sheet for every website; Customize panel and themes work on iPhone as on the Mac.
- README rewritten as a full guide to every feature and how it works.

## Checked
- 74 tests across window, layout, workspace, split-view, theme and toolbar classes pass; the new drag-between-windows path was also run with real (synthetic) mouse events on a Debug build and the page showed after the drop.
