# Browser Setu 0.3.3 (build 21)

iPhone/iPad: TestFlight build 21. Same version, higher build number. The Mac app is not part of this build.

## Fixed: the keyboard opening by itself (iPhone)
- **A swipe on the address pill that changed tabs also counted as a tap on the pill**, so the keyboard opened on the tab you swiped to, with its address selected. A tap within half a second of a swipe is now ignored.
- **A new tab no longer raises the keyboard** unless the new-tab page is set to Blank. Home, a custom address and private tabs show their own page; swiping past the last tab makes one of these and used to cover it with the keyboard.
- **The address field can be copied from and pasted into.** The dimming layer behind it sat above the field and took every touch meant for it. "Paste and Search" and "Copy Link" now say what happened when there is nothing to paste or pasting is switched off.

## Fixed: captchas and "verify you are human" (iPhone)
- **The browser now introduces itself exactly as Safari does** ("…Version/26.0 Mobile/15E148 Safari/604.1"). Before, the "Version" part was missing, which bot checks (Cloudflare, Google) read as an unusual browser, so sites like Claude, GitHub, Brave Search and Google Search asked for verification often. This should reduce the checks; it cannot promise none, as those services also weigh your network and history. Not yet checked on those sites.
- **Typing in a private tab no longer looks up site names** through the DNS resolver, nor does it when a proxy is on.

## New: tabs
- **Landscape (iPhone): a row of open tabs**, as in Safari. One glass capsule with each tab's icon and name, the tab in front lifted with a close cross, a plus for a new tab, long-press for the tab menu. The toolbar above it now spreads across the width.
- **The tab overview on iPhone, rebuilt.** A solid background (the page no longer shows through the controls), Select, Tabs / Private and Done in one row, search below, taller cards, larger close buttons, New Tab and a close menu at the foot.
- **Close menu:** Close Blank Tabs, Close Other Tabs, and Close All (asks first; with more than five tabs it saves a restore point).
- **Swipe a card sideways to close it** — a short flick is enough — and a vertical drag always scrolls the list.

## New: the bar and the page
- **Reading a page, the bar shrinks into a small round button at the right edge** showing only the site's icon (a ring fills while the page loads). It grows back out of the same corner when you tap it or scroll back. The two morph together, with no blank moment.
- **A soft blur behind the clock** so the time and signal stay readable over a white page.
- The reload arrow no longer shows on a blank page.

## New: the start page
- **A photograph behind the page** (Earthset, bundled with the app, nothing is fetched), drifting very slowly. It stands still for Reduce Motion, Animation Off and Low Power Mode. Plain and Gradient are still in Customize.
- **One grid of site icons.** Often Visited uses the same tiles as Favorites; one site is one tile, named by its site ("Equifax", not three pages of it).
- **Recently closed is one row of Reopen chips**, one per site. The empty Favorites box is a single "Add a favorite" line. The footer says "Protection on", with the number of tracking links cleaned when there are any; Tools and Customize are small icon buttons.
- This page is shared with the Mac app, which compiles with it; it was not run on the Mac for this build.

## New: a smoothness recorder (Settings › Performance and Pages)
- Counts frames that came late and files them under what you were doing (switching tabs, scrolling, opening the address bar or overview, loading), and which part of the app made the whole screen redraw. **Copy the Report** puts it on the clipboard: counts and symbol names only, no addresses or titles. It keeps nothing after you quit and sends nothing. It holds the screen at its top refresh rate while it runs, so it uses more battery.

## Known limits
- Checked on a real iPhone by capturing its screen; **not checked by hand**: the grow-back animation of the round button, swipe-to-close, the landscape capsule with many tabs, the Mac start page, and iPad.
- The first build with the recorder: its numbers have not been read yet.
- Landscape has no "hide the tab row" setting yet (Safari has one).
- UI tests (`iOSUITests`) still describe the 0.2.0 layout and are not run.
