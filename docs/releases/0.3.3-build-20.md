# Browser Setu 0.3.3 (build 20)

Mac: notarized DMG. iPhone/iPad: TestFlight build 20. Same version, higher build number.

## Added: four lookups, each only when you press its button
- **Saved copy of a page that will not load.** The error page now has "Look for a saved copy on the Internet Archive". It sends the page's address **without its query or fragment** and opens the copy in the same tab. Addresses on a private network are never sent.
- **Security headers.** The site panel has "Check Security Headers with Mozilla" (HTTP Observatory). It sends only the site's name and shows the grade, the tests passed and a link to what to fix.
- **Currency.** Select an amount ($250, €40, 40 €, ₹1,200, USD 250) and press Convert in the selection actions: your currency, dollars and euros at the European Central Bank's rate (frankfurter.dev). Only currency codes are sent. A "$" is read as US dollars.
- **Citation from a paper's DOI.** Tools › Copy Citation from DOI (APA, MLA or Plain), and the command palette. Finds the DOI on the page and copies the exact reference from Crossref.

None runs by itself, none sends a cookie or a referrer, and each is listed in the README's "What leaves your device" table and the privacy audit's allowed list.

## Also in this build
- Windows: a link opened from another app opens as a tab in the window in front; windows come back once at the next start (build 19).
- Tabs open next to the tab they came from and close back to it (build 19).

## Known limits
- The services are crowd-sourced public ones: the Internet Archive rate-limits quick repeated use ("busy, try again in a minute"), and Mozilla and Crossref can be slow.
- European number formats (1.299,99 €) are not read as amounts; "1,299.99" and "1 299" are.
- Currency covers the 30 or so currencies the European Central Bank publishes (no rouble).
