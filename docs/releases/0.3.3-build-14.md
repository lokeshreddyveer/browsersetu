# Browser Setu 0.3.3 (build 14)

Mac: notarized DMG. iPhone/iPad: TestFlight build 14. Same version, higher build number.

## Added since build 13
- **Animated themes** (16): Aurora, Rainy Night, Snowfall, Fireflies, Deep Sea, Starry Night, Cherry Blossom, Meteor Shower, Code Rain, Synthwave, Bubbles, Lava Lamp, Thunderstorm, Cartoon Clouds, Party, Arcade. Drawn in code; they show on the browser's own surfaces (window, toolbar, tabs, sidebar, docked panels, Settings) and never behind a web page. They stand still with Animation Off, Reduce Motion or Low Power Mode, and pause when the window is inactive. "Animated backdrop" sets Subtle, Medium or Strong.
- **Photo themes** (7): five NASA images (Webb, Hubble, Blue Marble, Earthset, Andromeda) and two public-domain paintings from The Met (The Great Wave, Wheat Field with Cypresses). Credits are in each theme's note and under Acknowledgements and Licences.
- **Your own animated theme:** a Backdrop choice in the custom theme editor.
- **Site colour:** give one website its own toolbar colour from the tab menu.
- **Icon style:** toolbar icon weight and site icon shape, which now redraw at once.
- **Animation setting:** Off, Calm, Standard, Snappy or Lively for the whole interface.
- **Theme gallery:** long groups show six with "Show All".
- Start page rises into place and its glow follows the time of day; animated speaker on a tab playing sound; smoother download ring; light tap when switching tabs on iPhone.
- **Faster large downloads:** files of 8 MB or more are fetched in up to six pieces where the server allows it.

## Fixed
- Downloads header no longer wraps; download progress is published four times a second.
- Lighter background checks (sound, scroll position) to keep switching and scrolling quick.
- Optimized (Release) builds are now what is installed for testing.

## Checked
- New unit tests compiled and passed on the Mac when added; Mac and iOS builds compile.
