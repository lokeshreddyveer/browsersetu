# Browser Setu 0.3.0 (build 4)

Mac: notarized and stapled DMG (SHA-256 d45c3753150b5a3a1e4bfd8d1e7fb0c09ceea27034fb1651d49bc2cde452e95d), installed here and launched; not yet published to the update feed. iPhone/iPad: uploaded to TestFlight as build 4. Built 17 October 2026.

## New
- **Sync:** a switch for each kind of thing (bookmarks, workspaces, sessions, open tabs, settings, site rules, history, passwords); history sync (opt-in, the 800 most
  recent pages, deletions travel); send a tab to another device; more rules and styles sync; a status that says what is wrong, and how full iCloud's space is.
- **Themes:** ten classic palettes; theme import and export; accent from the photo; contrast warning; a Customize panel on the start page; icon size; a style sheet for every site.
- **Search and layout:** typo-tolerant search across tabs; three-panel split view; certificate summary (organisation name beside the address, in site info).
- **Privacy:** guest window (Mac); JavaScript off per site; never-sleep list; fingerprint randomizing, De-AMP and YouTube ad skipping; leaked-password check; calculator and unit conversions.
- **Documents:** PDF editor with signing, redaction and page tools; document preview. Mouse gestures (Mac).
- **Polish:** accessibility labels, text-size scaling on iPhone, high-contrast outlines, keyboard focus rings on the start page, no white flash behind loading pages.
- The Chrome Web Store request now reports a newer Chrome version, so extensions such as Bitwarden can be fetched.
