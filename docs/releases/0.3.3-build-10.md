# Browser Setu 0.3.3 (build 10)

Mac: notarized, stapled DMG (replaces the build 8 file on the same release). iPhone/iPad: TestFlight build 10. Same version number, higher build number.

## Added since build 8
Saving passwords that works (frames, a typed-password card, iCloud Keychain option, passwords in the backup), pop-up handling, YouTube ad blocking on by default with updatable data-only rules, an iPhone autoplay guard, right-click menus,
drag-to-customize buttons, library panels, a redesigned start page, themes (Pure Black, schedule), Settings as a tab, first-run setup, message cards, plus the audit fixes below.

## Fixed in the audit
- The browser's own page scripts were removed by the user-scripts installer, so no sign-in, pop-up gesture or link was ever noticed. Break mode and page actions silently did nothing. Both fixed.
- Crash-recovery `try!` replaced by a fallback chain; SBOM version and toolchain checks; stale release records.
- Keychain "delete all" removed only one item on a Mac; a test no longer uses the real default profile.
- Smoothness: icon announcements are batched, page-load progress is stepped.

## Checked
- 117 of 118 selected tests passed after the changes; the one failure needs a signed build. A full run earlier passed 506 tests; scale tests (hundreds of tabs) take many minutes and were run separately or skipped.
- Compiler: no warnings in the app's own code.

## Not checked
- Live YouTube, live sign-ins (App Store Connect, Google), real two-device iCloud Keychain or sync, VoiceOver, and most new screens were not looked at on screen.
