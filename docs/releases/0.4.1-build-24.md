# Browser Setu 0.4.1 (build 24)

## What's new
- **Video tools are your choice.** ffmpeg and yt-dlp are optional downloads now, not part of the app. Install them from Settings > Media (or the optional step in first-run Setup) whenever you want video and audio downloads. You see the download size first and nothing downloads without your yes. Each tool can be updated, repaired or removed in Settings.
- **A smaller app.** The download is about 33 MB.
- **YouTube works without Node or Deno.** A small built-in JavaScript runner, sandboxed and verified, answers YouTube's puzzles for yt-dlp.
- **Checked before it runs.** Every tool is checked (SHA-256, Developer ID signature, Team ID, Apple notarization, processor type) before it is installed.
- **Updates show what changed.** After an update the opening scene plays and a "What's new" page follows; the setup questions are asked only on a first install.

## Fixes
- Explorer reads huge or hostile robots.txt files in bounded time.
- A fresh profile starts quickly.

## Optional downloads and licences
- yt-dlp 2026.10.26 and ffmpeg/ffprobe 9.0.2 (Apple silicon) are hosted as separate release assets: `media-tools-yt-dlp-2026.10.26` and `media-tools-ffmpeg-9.0.2`.
- Complete corresponding source for the open-source components, with SHA-256 list and notices: https://github.com/lokeshreddyveer/browsersetu/releases/tag/sources-0.4.1-build24
