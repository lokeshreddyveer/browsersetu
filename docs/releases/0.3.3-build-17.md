# Browser Setu 0.3.3 (build 17)

iPhone/iPad: TestFlight build 17. Same version, higher build number.

## Added since build 16
- **A visible Tools menu.** Daily Digest, Feeds / Tasks / Vault / Clipboard, Reading List, the site privacy grade and Clear Everything Now are now plain menu rows: in the iPhone menu, the iPad ⋮ menu, the Mac menu bar, and as a Tools button on the new tab page. They no longer depend on typing ">" in the address bar.
- Tools also lists Screenshot and Mark Up, Reopen My Last Session, Watch This Page for Changes and **All Commands…**, which opens the address bar ready for the full command list.
- **Plain-word history search works in the normal address bar:** type "pasta recipe last week" and matching pages from then appear first. No ">" needed.
