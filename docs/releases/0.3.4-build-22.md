# Browser Setu 0.3.4 (build 22)

Written 3 November 2026 from the comparison with LibreWolf, Waterfox, ungoogled-chromium, Orion and Zen (see `docs/ROADMAP-NEXT.md`). Everything marked "off" is off until you turn it on. The last section says what was tested and what was not.

## New: tabs and workspaces
- **Essentials** (up to 12): sites kept above your tabs in every workspace. Tab menu › Add to Essentials, or drag a tab onto the Essentials. An Essential keeps the container it was made in, never opens in another one, and survives switching workspaces without copies. Closing its page (⌘W) lets go of the page but keeps the Essential. Mac sidebars and the iPhone tab overview.
- **Pinned tab addresses**: a pinned tab's menu has Reset to Pinned Address, Set Current Page as Pinned Address, Edit Pinned Address… and Reset Automatically on Workspace Switch. Only web addresses are accepted (no scripts, files, or addresses with a password in them). The address is saved with the profile and synced with "Site rules and styles".
- **Clear Tabs**: closes the unpinned, unlocked tabs of the workspace (Essentials and pinned tabs stay). Sidebar "Clear" button, command palette, iPhone overview menu. Undo on the message that follows; large clears (8 or more) ask first, with "Close and Don't Ask Again". Undo opens the first 5 tabs and brings the rest back asleep, so a big undo is not a hundred page loads.
- **Find my tab**: when the tab in front has scrolled out of view in a sidebar list, a small button on the top or bottom edge shows its icon and scrolls back to it. The iPhone tab overview opens scrolled to the current tab.
- **Close Tabs Above / Below**, **Clear Unpinned Tabs** in the tab menu. A red dot on a tab using the camera or microphone.
- **Mac tab switches** (off): double-click a tab to close it, hide the close cross, close the window with its last tab.
- **Groups nest up to five levels**; a group cannot be moved inside itself or past the limit.
- **Workspace themes**: a workspace can have a gradient (two or three colours, an angle, "Generate" for a complementary palette), shown as a faint wash at the top of the Mac sidebar and on its icon tile in Settings. The first colour becomes the workspace's accent, lightened or darkened until it can be seen in the light and the dark look. The editor shows both looks and says whether text stays readable.
- **`--space`**: `open -n -a "Browser Setu" --args --space Development` (or the app's own binary with `--space`) shows that workspace; `open "browsersetu://space?name=Development"` and a Shortcuts action do the same for an app that is already running. A name that matches nothing, or more than one workspace, gets a clear message. Setting: open it in a new window.

## New: Glance
- A link opens in a floating preview over the page: Option-click (or Control-click, or only from the link's menu) on the Mac, "Open in Glance" when you touch and hold a link on iPhone. Back, forward, reload, copy link, open as a tab, close. It browses in the page's own container (private if the page is private), cannot open pop-ups of its own, leaves no history unless you open it as a tab, and closes when you pick another tab or close the page it came from. "Use a temporary session" gives it storage that is deleted when it closes.

## New: address bar
- **Learned suggestions**: the sites you use most, in the workspace you are in, and the results you chose before for the same typing, rise to the top; a clear match is lifted to just under the typed text. Worked out on the device from your history, kept in the profile folder, bounded, never learned from private tabs, guest windows, internal pages or sites you exclude. Settings › Search › Reset Learned Suggestions.
- **Control+Return** completes a bare name to its `.com` address. Mojeek and Kagi search presets. A different search engine for private tabs.

## New: privacy
- **Global Privacy Control** (on): `navigator.globalPrivacyControl`, and the `Sec-GPC: 1` header on iOS and macOS 27 and later.
- **Links no longer report clicks** (on); **tracker redirect pages are skipped** (on); more tracking parameters removed.
- **Privacy levels**: Standard, Strict, Paranoid. Strict leaves fingerprint noise off because it makes captcha providers ask more often.
- **Keep websites away from your home network** (off), **refuse Google analytics, ads and fonts** (off), **refuse social widgets** (off), **Load in Lockdown Mode** per site.
- Fingerprint noise now also nudges text and element sizes by a few millionths.

## New: other
- **Feeds**: Find Feeds on This Page, Import and Export OPML. Spell check is on by default in text boxes on the Mac.
- **Download animation**: a download you start flies a small dot to the Downloads button (not for queued, scheduled or resumed ones, at most one every two seconds, none with Reduce Motion); the button shows a check mark when a download finishes. Mac toolbar button and the iPhone dock button when it is shown.
- **Sync problems** are announced once outside Settings.

## Fixed (from build 21)
- Captchas: the browser introduces itself exactly as Safari does. Typing in a private tab no longer looks up site names.

## Measured, not built
- A spare, ready web view for new tabs: on the Mac only the very first web view in the app is slow (about 82 ms to create, 250 ms to load); every later one takes about 3 ms and 40 ms. A spare would save nothing.

## What was and was not verified
Tested by automatic tests on the Mac (all passing when this was written; see the list below): the pure rules (Essentials limits, profiles and duplicates; address validation; argument and workspace-name parsing; gradient maths and contrast; ranking and the learned store; flight policy; tab-visibility rule), the model flows (add, remove, open, close and survive workspace switches; container rules; pinned reset and workspace-switch reset; Clear and Undo; Glance session rules, promotion with the same web view, pop-up handling; nested group limits), and, in a real web view, Global Privacy Control, link pings, measurement noise and the home-network blocker.

**Not verified by running it:** anything on a real iPhone or iPad (only compiled); the Glance trigger clicks and menus; the Essentials, locator and workspace-gradient views drawn on screen; the download flight's path and timing; `--space` from a real Terminal with a second copy of the app; learned ranking over weeks of real use; Lockdown Mode on real sites; the Strict and Paranoid levels on everyday sites; iCloud sync of pinned addresses between two devices. Treat these as unproven until tried by hand.

## Known limits
- Global Privacy Control's header needs a system at version 27 or later; older systems send the script signal only.
- `open -a "Browser Setu" --args --space X` on an app that is already running only brings it forward (macOS gives arguments to a newly started copy only); use `open -n`, the app's binary, or the `browsersetu://space` link.
- A workspace's id is its name today, so `--space` matches the name (exactly, then ignoring capitals when that is unambiguous).
- Essentials are not synced between devices (their containers are device-local); each window keeps its own live page for an Essential.
- Glance on the iPhone is offered from the link's touch-and-hold menu only.
- WebKit is itself adding Local Network Access checks (WebKit bug 250607 and its children, July 2026); the home-network switch is the stopgap.
