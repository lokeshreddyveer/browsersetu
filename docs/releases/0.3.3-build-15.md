# Browser Setu 0.3.3 (build 15)

iPhone/iPad: TestFlight build 15. Same version, higher build number.

## Added since build 14
- **Widgets:** Search, Favorites, Blocked Today and Reading List, redrawn with a gradient design and proper Lock Screen versions.
- **Control Center and Lock Screen buttons** (iOS 18): New Tab, Private Tab and Shared Inbox.
- **Share sheet:** send a link or text to Browser Setu from any app; it lands in the Inbox.
- **Mac:** Control-Option-Space opens the menu-bar search from any app.
- **Link previews:** press and hold a link to preview the page.

## Fixed
- **Accent** now stays as you chose it; a theme no longer repaints it. "Reset Appearance" gives control back to the theme.
- **Density** now changes the address-bar height on iPhone.
- Removing a profile retries when WebKit is still releasing its data, so the data is really deleted.
- The browser's own page scripts for scroll position now run in an isolated world, out of reach of web pages.

## Under the hood
- The multi-connection downloader's types are renamed to "Piece" to keep the privacy audit's word list meaningful. The audit now lists every file allowed to open a network connection, and each one runs only when you start it.
