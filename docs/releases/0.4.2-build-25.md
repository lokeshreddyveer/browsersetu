# Browser Setu 0.4.2 (build 25)

## What's new
- **Updates show what changed.** After an update the opening scene plays and a "What's new" page follows; the setup questions are asked only on a first install.
- **Videos have their names.** In the toolbar's video list each video shows its own title (or its ID when the page gives none), instead of identical rows.
- **Added video links open the video options.** A YouTube, TikTok or Instagram link you add no longer saves the web page as an HTML file; it opens what can be saved, with the offer to install the video tool if it is missing.
- **Optional tools, plainer names.** Setup, Settings and Downloads call them "Video download tool" and "Media processing tool".

## Carried from 0.4.1
- Video download and media processing tools are optional downloads (Settings > Media, or the optional Setup step), shown with their size first; nothing downloads without your yes. The app is about 33 MB.
- A small built-in JavaScript runner (sandboxed) answers YouTube's puzzles; no Node or Deno is needed.
