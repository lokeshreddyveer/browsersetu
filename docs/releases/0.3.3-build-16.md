# Browser Setu 0.3.3 (build 16)

Mac: notarized DMG. iPhone/iPad: TestFlight build 16. Same version, higher build number.

## Added since build 15
- **Look-alike address warning:** pages that imitate a well-known site are held back until you choose to continue.
- **Privacy grade (A to F)** for the page in front, with reasons, in *This site…*; per-site zoom, light or dark look, private-tab rule and permission "Take Back" in the same place.
- **Clear Everything Now:** one confirmed step that closes all tabs and erases history, data, copied text and the shared inbox.
- **Daily Digest:** reading list, feeds, tasks and time on sites in one list.
- **Automatic switching:** time rules that move to a workspace as their time begins (Mac).
- **Ask in plain words:** "pasta recipe last week" finds it in history from the command palette.
- **Tab groups travel** between devices; the sleeping-tab moon and reason.
- **Mac Share menu entry** (App Store build) and the iPhone/iPad share sheet.
- **Control Center and Lock Screen buttons** (iOS 18) and redrawn widgets.
- **Mac menu-bar search hotkey:** Control-Option-Space.
- **Link previews** on press-and-hold.

## Fixed
- iPhone and iPad now register the `browsersetu://` link scheme. Before this, widget taps, Control Center buttons and Shortcuts links did not open the app.
- Accent colour stays as chosen when a theme changes; density changes the iPhone address bar height.
- Removing a profile retries until WebKit has released its data.
- The browser's own scroll-restore scripts run in an isolated world.
