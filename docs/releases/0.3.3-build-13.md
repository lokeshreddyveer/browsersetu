# Browser Setu 0.3.3 (build 13)

Mac: notarized DMG. iPhone/iPad: TestFlight build 13. Same version, higher build number.

## Added since build 12
- Faster large downloads: files of 8 MB or more from servers that allow it are fetched in up to six pieces at once (then three, then one if the server refuses), with a setting to turn it off. Pausing is not available for these.

## Fixed
- Downloads panel header no longer wraps (diagnostics and clear are icons); progress is published four times a second instead of for every chunk.

## Checked
- A 100 MB download through the app matched a plain download byte for byte. New downloader tests pass.

## Not checked
- Speed gain on real sites: it depends on the server limiting single connections; a slow connection of your own is not helped.
