FFmpeg 9.0.2 as distributed with Browser Setu (optional media tool "ffmpeg")
=============================================================================

What this is
  The files ffmpeg and ffprobe in ffmpeg-9.0.2-arm64.zip are FFmpeg 9.0.2 (https://ffmpeg.org), built by the Browser Setu publisher as LGPL-only, statically linked programs for Apple silicon (arm64).
  They are free software under the GNU Lesser General Public License, version 2.1 or later. They were configured with --disable-gpl --disable-nonfree --disable-version3, use no external libraries
  (--disable-autodetect) and open no network connections (--disable-network). The licence texts (COPYING.LGPLv2.1, COPYING.LGPLv3, LICENSE.md) are inside the zip, next to BUILDINFO.txt.

Changes made by the publisher
  1. The FFmpeg source is UNMODIFIED. It is the upstream release archive, checked against its published SHA-256 before it is built.
  2. The programs are built with a reduced feature set (the configure line is in BUILDINFO.txt and below), which only removes components.
  3. The finished programs are code-signed with a Developer ID certificate (Team X4MH29QNRS) with the hardened runtime, and the zip was notarized by Apple. Signing changes the file bytes, not the source.

How to rebuild (and replace) the programs
  1. Download the source archive above and check its SHA-256.
  2. Run:  sh build-ffmpeg-minimal.sh OUT_DIR arm64     (the script downloads and checks the archive itself, configures, builds and writes ffmpeg, ffprobe and BUILDINFO.txt to OUT_DIR).
  3. Because the programs are statically linked, this is the way to use a modified FFmpeg library with them: edit the source, rebuild, and use your own ffmpeg. Browser Setu can be pointed at a program you
     installed yourself (Settings > Media), so you are not tied to the copy we distribute.
