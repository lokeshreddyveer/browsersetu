yt-dlp 2026.10.26 as distributed with Browser Setu (media tool "yt-dlp")
================================================================================

What this is
  yt-dlp-2026.10.26-arm64.zip contains the yt-dlp program (https://github.com/yt-dlp/yt-dlp) in the form its authors publish for macOS: a PyInstaller "onedir" build that bundles the Python interpreter and
  libraries. The yt-dlp source code is under The Unlicense. The bundled third-party components carry their own licences. Upstream's licence list for this build includes mutagen (GPL-2.0-or-later) and
  certifi (MPL-2.0); the PyInstaller bootloader inside the executable is GPL-2.0-or-later with the PyInstaller bootloader exception (see PYINSTALLER-6.22.0-LICENSE.txt). As the upstream project states, the
  combined executable is distributed under the GNU General Public License, version 3 or later. The full texts of the component licences are in the package (_internal/THIRD_PARTY_LICENSES.txt, and the per-package
  licence files under _internal) and in this Notices folder (YT-DLP-THIRD_PARTY_LICENSES.txt).
  Upstream's licence list is written for all of its platform builds and also names GNU Readline, libintl, libidn2, libunistring and the GCC runtime. We found none of those in the files of this macOS build (its
  readline module links the macOS system library libedit; the compiled curl-impersonate library contains curl, BoringSSL and nghttp2). They are mentioned only so that nothing is hidden: the licence review is not finished.

Changes made by the publisher to the upstream release package (yt-dlp_macos.zip, sha256 20d98fa608998eff87d1d35a6e9fb65e4b874639a6cc89addc19da3becde3ef1)
  1. Architecture: the upstream universal (x86_64 + arm64) programs were thinned with lipo to arm64 only. Nothing was recompiled and no source was changed.
  2. Python.framework layout: upstream's archive carries plain copies where a macOS framework expects links (Versions/Current, Python, Resources). The standard links were restored so the framework can be signed.
  3. Code signing: every Mach-O file was re-signed with a Developer ID certificate (Team X4MH29QNRS) with the hardened runtime, replacing upstream's ad-hoc signature. The result is the package yt-dlp-2026.10.26-arm64.zip,
     27,310,492 bytes, sha256 b82fec9f012524ac2504c45e24b449cf7a86185c3d6abd2d49932843a818c3d9; Apple notarization submission 6f4291e4-012c-43b8-ba4f-140a98bb59c2 (status Accepted) is for exactly this zip.
  These are the only differences between this zip and the upstream release asset.
